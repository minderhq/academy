## 8. PRINT PRODUCTION CONSIDERATIONS

### Paper Specifications
- **Weight:** 80-100 gsm (standard book paper)
- **Type:** Cream or white offset paper
- **Opacity:** High (for double-sided printing with code blocks)
- **Finish:** Matte (better for reading technical content)

### Cover Specifications
- **Material:** 300gsm cardstock with laminate
- **Binding:** Perfect bound for volumes under 400 pages
- **Color:** Full color cover, black & white interior
- **ISBN:** Required for retail distribution

### Layout Considerations
- **Font:** 10-11pt for body text, monospace for code
- **Margins:** 2cm (standard for technical books)
- **Line spacing:** 1.2-1.4 for readability
- **Code blocks:** Gray background, syntax highlighting
- **Diagrams:** Converted to high-resolution images

### Cost Estimates (Per Volume)
- **Print-on-demand (POD):** $8-15 per volume (250-300 pages)
- **Offset print (1000+ copies):** $5-8 per volume
- **7-volume set (POD):** $56-105 total
- **7-volume set (offset):** $35-56 total
