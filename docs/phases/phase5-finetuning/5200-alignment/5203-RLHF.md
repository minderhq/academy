## Overview

This module will cover RLHF (Reinforcement Learning from Human Feedback), the foundational alignment method used to train models like ChatGPT and Claude.

- **PPO Implementation** - Proximal Policy Optimization
- **KL Divergence** - Preventing reward hacking
- **Scaling Laws** - How RLHF scales with model size
- **RLHF vs DPO** - Comparison with Direct Preference Optimization
