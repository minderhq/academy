# 5300: Synthetic Data - Prerequisites

## Before You Start

This module covers synthetic data generation for AI training.

**Required Knowledge:**

### ML Fundamentals
- Data quality and distribution
- Overfitting and underfitting
- Training-validation-test splits
- Data augmentation

### Generative Models
- LLMs for text generation
- Prompt engineering
- Few-shot learning
- Generation quality evaluation

### Data Engineering
- Data pipelines
- Validation and filtering
- Deduplication
- Privacy considerations

### If you're not familiar:

**Review Resources:**
- "Synthetic Data for Deep Learning" survey papers
- "Data-centric AI" research (Andrew Ng)
- "The Synthetic Data Vault" paper
- Hugging Face datasets documentation

**Estimated Review Time:** 2-3 hours
