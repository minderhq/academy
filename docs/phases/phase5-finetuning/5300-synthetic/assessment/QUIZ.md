## Questions

### 1. What is synthetic data in LLM context?

A) Data from synthetic benchmarks
B) Data generated by other LLMs
C) Artificial training data
D) All of the above

### 2. What is the primary benefit of synthetic data?

A) Always higher quality
B) Cheaper and faster to generate than human data
C) No bias
D) Free from hallucinations

### 3. What is distillation in LLM context?

A) Compressing liquid
B) Training smaller model to mimic larger model
C) Data compression
D) Model pruning

### 4. What is model merging?

A) Merging training datasets
B) Combining weights from multiple trained models
C) Ensemble methods
D) Multi-task learning

### 5. Which method combines weights from fine-tuned models?

A) Stochastic Weight Averaging
B) Linear merging of checkpoints
C) Task Arithmetic
D) All of the above

### 6. What is a risk with synthetic data?

A) Model collapse
B) Amplification of biases
C) Quality degradation
D) All of the above

### 7. What is model collapse?

A) Model stops working
B) Model loses diversity and generates degenerate output
C) Model forgets training
D) Model overfits

### 8. What is federated learning?

A) Training across multiple institutions without sharing data
B) Federated database training
C) Distributed training
D) Cloud training

### 9. What is the main challenge of federated learning?

A) Communication overhead
B) Privacy preservation
C) Data heterogeneity
D) All of the above

### 10. What is "self-instruct"?

A) Self-supervised learning
B) Using LLM to generate its own training instructions
C) Self-training loop
D) Instruction following

---

## Answers

1. **D** - All descriptions apply to synthetic data
2. **B** - Primary advantage: cheaper, faster, scalable
3. **B** - Knowledge distillation: small model learns from large teacher
4. **B** - Merge weights from multiple models (e.g., merge wizard, mergekit)
5. **D** - All methods exist for model merging
6. **D** - All are significant risks with synthetic data
7. **B** - Degenerative process where models trained on synthetic data lose diversity
8. **A** - Distributed training keeping data local
9. **D** - All are challenges in federated settings
10. **B** - LLM generates instruction-response pairs for fine-tuning
