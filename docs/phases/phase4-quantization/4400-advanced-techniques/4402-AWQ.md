## Abstract

AWQ (Activation-aware Weight Quantization) is a post-training quantization method that considers activation distributions when quantizing weights, achieving better accuracy at the same bit-width.

## What is AWQ?

**Key Insight:** Only ~1% of weights are significant for model performance. AWQ identifies and protects these weights while aggressively quantizing others.

```text
Traditional PTQ:
All weights ──> Same precision ──> Some important weights degraded ❌

AWQ:
Analyze activations ──> Identify important weights ──> Protect + Quantize ✅
```

## How AWQ Works

### Step 1: Activation Analysis

AWQ collects activation statistics to identify important weights:

```python
import torch
import torch.nn as nn

def collect_activation_stats(model, calibration_data):
    """
    Collect per-channel activation magnitudes for each Linear's INPUT.

    A scalar per layer would collapse "activation-aware" ranking into
    plain weight-magnitude ranking (measured: scalar stats beat RTN by
    <0.5% weighted error; per-channel stats by ~17%).

    Returns: {layer_name: [in_features] mean |activation|}
    """
    activation_scales = {}

    # Hooks on the INPUT (pre-hook): AWQ scales input channels, and the
    # input of a layer is what its weights multiply
    def make_pre_hook(name):
        def pre_hook(module, args):
            x = args[0].detach().abs()
            channel_magnitude = x.mean(dim=tuple(range(x.dim() - 1)))
            # Running max: a plain assignment is overwritten by every
            # batch, keeping only the last calibration batch
            if name in activation_scales:
                activation_scales[name] = torch.maximum(
                    activation_scales[name], channel_magnitude
                )
            else:
                activation_scales[name] = channel_magnitude
        return pre_hook

    hooks = []
    for name, module in model.named_modules():
        if isinstance(module, nn.Linear):
            hooks.append(module.register_forward_pre_hook(make_pre_hook(name)))

    # Run calibration data
    with torch.no_grad():
        for batch in calibration_data:
            _ = model(**batch)

    # Clean up hooks
    for hook in hooks:
        hook.remove()

    return activation_scales
```

### Step 2: Weight Importance Score

```python
def compute_importance_score(weight, activation_magnitude):
    """
    Compute importance score for each weight.

    Score = |activation_j| × |w_ij| — per-channel magnitudes broadcast
    across the [out_features, in_features] weight matrix, so a salient
    input channel protects its whole column.

    (The paper's optimum is a smoothed activation-power scale; the
    linear form keeps the sketch readable while preserving the ranking.)
    """
    importance = activation_magnitude[None, :] * weight.abs()
    return importance
```

### Step 3: Selective Quantization

```python
def awq_quantize(weight, activation_magnitude, bit_width=4, keep_ratio=0.01):
    """
    AWQ quantization with weight preservation.

    Pedagogical mixed-precision form: salient weights stay FP16.
    Production AWQ never stores FP16 outliers — it rescales per channel
    (w_j -> w_j * s, x_j -> x_j / s) so salient directions quantize to
    the same INT4 grid with no extra memory.

    Args:
        weight: [out_features, in_features]
        activation_magnitude: [in_features] per-channel magnitudes
        bit_width: Target bit-width for most weights
        keep_ratio: Fraction of weights to keep at FP16
    """
    # Compute importance scores
    importance = compute_importance_score(weight, activation_magnitude)

    # Select top-k weights to keep
    num_keep = int(weight.numel() * keep_ratio)
    threshold = importance.flatten().topk(num_keep).values[-1]

    # Create mask
    keep_mask = importance >= threshold

    # One scale per row over the UNPROTECTED entries — a single global
    # scale loses ~1.4x weighted error to per-row rounding. Rows whose
    # every entry is protected fall back to their full-range scale:
    # their FP16 outliers sit outside the quantized grid anyway.
    qmax = 2 ** (bit_width - 1) - 1
    masked = torch.where(keep_mask, torch.full_like(weight, float("inf")), weight.abs())
    row_max = masked.max(dim=1).values
    full_max = weight.abs().max(dim=1).values
    scale = torch.where(row_max.isinf(), full_max, row_max).clamp(min=1e-8) / qmax
    scale_mat = scale[:, None].expand_as(weight)

    weight_q = weight.clone()
    weight_q[~keep_mask] = torch.round(
        weight[~keep_mask] / scale_mat[~keep_mask]
    ) * scale_mat[~keep_mask]

    return weight_q, keep_mask
```

## Practical AWQ

### Using AutoAWQ

```python
from awq import AutoAWQForCausalLM
from transformers import AutoTokenizer

model_name = "meta-llama/Llama-2-7b-hf"

# Quantization config
quant_config = {
    "zero_point": True,  # Use zero-point
    "q_group_size": 128,  # Group size
    "w_bit": 4,  # 4-bit
    "version": "GEMM",  # GEMM version (faster)
}

# Load and quantize
model = AutoAWQForCausalLM.from_pretrained(
    model_name,
    device_map="auto",
    safetensors=True,
)
tokenizer = AutoTokenizer.from_pretrained(model_name)

# Quantize
from datasets import load_dataset

dataset = load_dataset("c4", "en", split="train")
calibration_data = [
    {"input_ids": tokenizer(example["text"], return_tensors="pt")["input_ids"]}
    for example in dataset.select(range(128))
]

model.quantize(calibration_data, quant_config)

# Save
save_path = "./llama-2-7b-awq"
model.save_quantized(save_path)
tokenizer.save_pretrained(save_path)
```

## AWQ vs GPTQ

| Aspect | GPTQ | AWQ |
|--------|------|-----|
| **Method** | Hessian-based | Activation-based |
| **Quantization Time (7B)** | ~30 min | ~20 min |
| **Accuracy @ 4-bit** | Good | Slightly better |
| **Inference Speed** | Fast | Faster (optimized kernels) |
| **Calibration Data** | Required | Required |
| **Implementation Complexity** | High | Medium |

## AWQ Parameters

### Zero Point

```text
# Zero-point allows asymmetric quantization
zero_point=True:  # Better accuracy, slightly slower
# Range: [-128, 127] for INT8

zero_point=False:  # Symmetric, faster
# Range: [-127, 127] for INT8
```

### Group Size

```text
# Similar to GPTQ
q_group_size=128:  # Default, good balance
q_group_size=64:   # Better accuracy
q_group_size=-1:   # Per-tensor, fastest
```

### Protection Budget (keep_ratio)

```text
# Fraction of weights kept at FP16 — the awq_quantize sketch's knob
keep_ratio=0.01:  # Keep top 1%
keep_ratio=0.005: # Keep fewer (more aggressive)
keep_ratio=0.02:  # Keep more (conservative)

# AutoAWQ's quant_config does not expose this: the paper grid-searches
# the per-group clip with an MSE sweep during quantization
```

## Custom Calibration for AWQ

```python
def domain_aware_awq(model, tokenizer, domain_texts):
    """Apply AWQ with domain-specific calibration"""

    # Tokenize domain texts
    calibration_data = []
    for text in domain_texts:
        tokens = tokenizer(
            text,
            return_tensors="pt",
            truncation=True,
            max_length=2048,
        )
        calibration_data.append({"input_ids": tokens["input_ids"]})

    # Quantize
    quant_config = {
        "zero_point": True,
        "q_group_size": 128,
        "w_bit": 4,
        "version": "GEMM",
    }

    model.quantize(calibration_data, quant_config)

    return model

# Example: Code-focused model
code_texts = [
    "def quicksort(arr):\n    if len(arr) <= 1: return arr",
    "import torch.nn as nn",
    "class BinarySearchTree:",
    # ... more examples
]

model = domain_aware_awq(model, tokenizer, code_texts)
```

## Multi-Quantization (Mixing Bits)

```python
def mixed_precision_awq(model, bit_config):
    """
    Sketch of per-layer bit dispatch.

    AutoAWQ has no per-layer bit API — production mixed-precision runs
    through GPTQ-style per-layer configs or QAT (see 4305); the layer
    quantization machinery itself is omitted here.
    """

    for layer_name, layer in model.named_modules():
        if isinstance(layer, nn.Linear):
            # Determine bit-width for this layer
            bits = get_bits_for_layer(layer_name, bit_config)
            # ... layer-level quantization machinery would attach here

    return model

def get_bits_for_layer(layer_name, config):
    """Bit-width for a module path like 'layers.14.self_attn.q_proj'.

    Keys are ranges such as 'layers.11-20' or bare heads like
    'embeddings'. A plain substring test (`pattern in layer_name`)
    never matches real module paths — parse the layer index and
    range-check it instead.
    """
    head, idx = layer_name.split(".")[:2]
    for pattern, bits in config.items():
        p_head, _, p_span = pattern.partition(".")
        if p_head != head:
            continue
        if not p_span:  # bare head like 'embeddings'
            return bits
        lo, hi = map(int, p_span.split("-"))
        if lo <= int(idx) <= hi:
            return bits
    return 4  # Default
```

## Converting Between Formats

```python
def awq_to_gptq(awq_model_path):
    """Illustrative sketch — qweight packing alone is not a converter.

    AWQ and GPTQ share the packed-INT32 qweight layout but differ in
    scale/zero-point layout and metadata; a real conversion repacks
    those too. In practice you quantize from the FP base per target
    format instead of converting.
    """

    # Load AWQ model
    model_awq = AutoAWQForCausalLM.from_quantized(awq_model_path)

    # Extract quantized weights
    quantized_weights = {}
    for name, param in model_awq.named_parameters():
        if 'qweight' in name:
            quantized_weights[name] = param

    # Create GPTQ-compatible state dict
    gptq_state_dict = convert_to_gptq_format(quantized_weights)

    # Save
    torch.save(gptq_state_dict, "model-gptq.pt")

    return gptq_state_dict
```

## Best Practices

1. **Domain-specific calibration:** Use calibration data from your target domain
2. **8-bit for embeddings:** First and last layers benefit from higher precision
3. **Enable fusion:** Always use `fuse_layers=True` for production
4. **Group size 128:** Default works well for most models
5. **Test before deploying:** Validate on domain-specific evaluation

## Summary

AWQ improves on naive PTQ with one observation: a small fraction of salient weights carries most of the accuracy, and activation distributions tell you which ones. Scaling and protecting those channels preserves accuracy at the same bit-width where uniform rounding would bleed it. This lesson covered the mechanism and the practical workflow, then the operational questions: when AWQ beats GPTQ and vice versa, how mixed-bit layouts trade a little accuracy for speed, and how to convert between formats when the runtime demands it.
