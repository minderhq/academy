# 4402: AWQ

## Abstract

AWQ (Activation-aware Weight Quantization) is a post-training quantization method that considers activation distributions when quantizing weights, achieving better accuracy at the same bit-width.

## What is AWQ?

**Key Insight:** Only ~1% of weights are significant for model performance. AWQ identifies and protects these weights while aggressively quantizing others.

```
Traditional PTQ:
All weights ──> Same precision ──> Some important weights degraded ❌

AWQ:
Analyze activations ──> Identify important weights ──> Protect + Quantize ✅
```

## How AWQ Works

### Step 1: Activation Analysis

AWQ collects activation statistics to identify important weights:

```python
def collect_activation_stats(model, calibration_data):
    """
    Collect activation magnitudes for each layer.

    Returns: Dictionary of {layer_name: activation_scale}
    """
    activation_scales = {}

    # Register hooks
    def get_activation_hook(name):
        def hook(module, input, output):
            activation_scales[name] = output.abs().max()
        return hook

    hooks = []
    for name, module in model.named_modules():
        if isinstance(module, nn.Linear):
            hook = module.register_forward_hook(get_activation_hook(name))
            hooks.append(hook)

    # Run calibration data
    with torch.no_grad():
        for batch in calibration_data:
            _ = model(**batch)

    # Clean up hooks
    for hook in hooks:
        hook.remove()

    return activation_scales
```

### Step 2: Weight Importance Score

```python
def compute_importance_score(weight, activation_scale):
    """
    Compute importance score for each weight.

    Score = |activation| × |weight|
    Higher score = more important
    """
    importance = activation_scale * weight.abs()
    return importance
```

### Step 3: Selective Quantization

```python
def awq_quantize(weight, activation_scale, bit_width=4, keep_ratio=0.01):
    """
    AWQ quantization with weight preservation.

    Args:
        weight: [out_features, in_features]
        activation_scale: Scalar or per-channel
        bit_width: Target bit-width for most weights
        keep_ratio: Fraction of weights to keep at FP16
    """
    # Compute importance scores
    importance = compute_importance_score(weight, activation_scale)

    # Select top-k weights to keep
    num_keep = int(weight.numel() * keep_ratio)
    threshold = importance.flatten().topk(num_keep).values[-1]

    # Create mask
    keep_mask = importance >= threshold

    # Quantize non-protected weights
    weight_q = weight.clone()
    scale = weight_q[~keep_mask].abs().max() / (2 ** (bit_width - 1) - 1)
    weight_q[~keep_mask] = torch.round(weight_q[~keep_mask] / scale) * scale

    # Keep important weights at FP16
    weight_q[keep_mask] = weight[keep_mask]

    return weight_q, keep_mask
```

## Practical AWQ

### Using AutoAWQ

```python
from awq import AutoAWQForCausalLM
from transformers import AutoTokenizer

model_name = "meta-llama/Llama-2-7b-hf"

# Quantization config
quant_config = {
    "zero_point": True,  # Use zero-point
    "q_group_size": 128,  # Group size
    "w_bit": 4,  # 4-bit
    "version": "GEMM",  # GEMM version (faster)
}

# Load and quantize
model = AutoAWQForCausalLM.from_pretrained(
    model_name,
    device_map="auto",
    safetensors=True,
)
tokenizer = AutoTokenizer.from_pretrained(model_name)

# Quantize
from datasets import load_dataset

dataset = load_dataset("c4", "en", split="train")
calibration_data = [
    {"input_ids": tokenizer(example["text"], return_tensors="pt")["input_ids"]}
    for example in dataset.select(range(128))
]

model.quantize(calibration_data, quant_config)

# Save
save_path = "./llama-2-7b-awq"
model.save_quantized(save_path)
tokenizer.save_pretrained(save_path)
```

## AWQ vs GPTQ

| Aspect | GPTQ | AWQ |
|--------|------|-----|
| **Method** | Hessian-based | Activation-based |
| **Quantization Time (7B)** | ~30 min | ~20 min |
| **Accuracy @ 4-bit** | Good | Slightly better |
| **Inference Speed** | Fast | Faster (optimized kernels) |
| **Calibration Data** | Required | Required |
| **Implementation Complexity** | High | Medium |

### Accuracy Comparison (Perplexity)

| Model | FP32 | GPTQ 4-bit | AWQ 4-bit | AWQ Advantage |
|-------|------|------------|-----------|---------------|
| Llama-2-7B | 12.4 | 13.1 | 12.9 | +0.2 |
| Llama-2-13B | 10.8 | 11.3 | 11.1 | +0.2 |
| Llama-2-70B | 9.2 | 9.6 | 9.5 | +0.1 |

## AWQ Parameters

### Zero Point

```python
# Zero-point allows asymmetric quantization
zero_point=True:  # Better accuracy, slightly slower
# Range: [-128, 127] for INT8

zero_point=False:  # Symmetric, faster
# Range: [-127, 127] for INT8
```

### Group Size

```python
# Similar to GPTQ
q_group_size=128:  # Default, good balance
q_group_size=64:   # Better accuracy
q_group_size=-1:   # Per-tensor, fastest
```

### Clip Ratio

```python
# Controls how many weights to preserve
clip_ratio=0.01:  # Keep top 1% (default)
clip_ratio=0.005: # Keep fewer (more aggressive)
clip_ratio=0.02:  # Keep more (conservative)
```

## Custom Calibration for AWQ

```python
def domain_aware_awq(model, tokenizer, domain_texts):
    """Apply AWQ with domain-specific calibration"""

    # Tokenize domain texts
    calibration_data = []
    for text in domain_texts:
        tokens = tokenizer(
            text,
            return_tensors="pt",
            truncation=True,
            max_length=2048,
        )
        calibration_data.append({"input_ids": tokens["input_ids"]})

    # Quantize
    quant_config = {
        "zero_point": True,
        "q_group_size": 128,
        "w_bit": 4,
        "version": "GEMM",
    }

    model.quantize(calibration_data, quant_config)

    return model

# Example: Code-focused model
code_texts = [
    "def quicksort(arr):\n    if len(arr) <= 1: return arr",
    "import torch.nn as nn",
    "class BinarySearchTree:",
    # ... more examples
]

model = domain_aware_awq(model, tokenizer, code_texts)
```

## Multi-Quantization (Mixing Bits)

```python
def mixed_precision_awq(model, bit_config):
    """
    Apply different bit-widths to different layers.

    bit_config = {
        'embeddings': 8,
        'layers.0-10': 8,
        'layers.11-20': 4,
        'layers.21-32': 4,
    }
    """

    for layer_name, layer in model.named_modules():
        if isinstance(layer, nn.Linear):
            # Determine bit-width for this layer
            bits = get_bits_for_layer(layer_name, bit_config)

            # Apply AWQ with specific bits
            layer_awq = apply_awq_to_layer(layer, bits=bits)

    return model

def get_bits_for_layer(layer_name, config):
    """Determine bit-width from config"""
    for pattern, bits in config.items():
        if pattern in layer_name:
            return bits
    return 4  # Default
```

## Best Practices

1. **Domain-specific calibration:** Use calibration data from your target domain
2. **8-bit for embeddings:** First and last layers benefit from higher precision
3. **Enable fusion:** Always use `fuse_layers=True` for production
4. **Group size 128:** Default works well for most models
5. **Test before deploying:** Validate on domain-specific evaluation
