## Abstract

GPTQ (GPT Post-Training Quantization) is a post-training quantization method that achieves near-FP32 accuracy at 4-bit precision without requiring retraining.

## What is GPTQ?

**Key Innovation:** GPTQ uses second-order information (Hessian) to intelligently quantize weights, minimizing the reconstruction error.

```text
Traditional PTQ:
Weight ──> Round to nearest INT4 ──> Large error ❌

GPTQ:
Weight ──> Analyze Hessian ──> Smart rounding ──> Minimal error ✅
```

## How GPTQ Works

### The Problem

Naively rounding weights to INT4 causes significant error:

```text
W_fp32 = [1.23, 2.45, 3.67, 4.89]  # Original weights
W_int4 = [1, 2, 4, 5]              # Naively rounded
Error = |W_fp32 - W_int4|^2        # Large error!
```

### The Solution: Optimal Brain Surgeon

GPTQ treats quantization as an optimization problem:

1. **Compute Hessian:** Measure how much each weight affects output
2. **Quantize in order:** Most important weights first
3. **Update remaining:** Compensate for errors in subsequent weights

```python
import torch
# Simplified GPTQ (Frantar et al., 2022, Alg. 1) — the full algorithm adds
# group-wise scales and block-processed Cholesky for speed

def gptq_quantize(weight, H, bit_width=4):
    """Quantize weights using GPTQ error compensation.

    Args:
        weight: [out_features, in_features]
        H: activation Hessian, 2 * X @ X.T on calibration activations
           [in_features, in_features]
        bit_width: Target bit-width

    Returns:
        Quantized weights
    """
    qmax = 2 ** (bit_width - 1) - 1

    # Damping keeps the factorizations numerically stable
    H = H + 0.01 * H.diag().mean() * torch.eye(H.shape[0])

    # Update factor: the UPPER-triangular Cholesky of the INVERSE Hessian.
    # (torch.linalg.cholesky returns lower-triangular L, whose L[j, j+1:]
    # is all zeros — the update would silently no-op)
    Hinv = torch.cholesky_inverse(torch.linalg.cholesky(H))
    U = torch.linalg.cholesky(Hinv).T

    weight_q = torch.zeros_like(weight)
    for i in range(weight.shape[0]):
        # One scale per row: abs().max() of a single weight would just
        # return that weight — and could be negative
        scale = weight[i].abs().max() / qmax
        w_work = weight[i].clone()
        for j in range(weight.shape[1]):
            weight_q[i, j] = torch.round(w_work[j] / scale).clamp(
                -2 ** (bit_width - 1), qmax
            ) * scale

            # Push weight j's error into the unquantized columns, weighted
            # by inverse-Hessian coupling — the off-diagonal term is what
            # makes GPTQ beat naive rounding (verified: beats RTN's
            # Hessian-weighted error on random 32-column rows)
            err = (w_work[j] - weight_q[i, j]) / U[j, j]
            w_work[j + 1:] -= err * U[j, j + 1:]

    return weight_q
```

## Practical GPTQ

### Using AutoGPTQ

```python
from transformers import AutoTokenizer
# auto-gptq is the classic API; GPTQModel (ModelCloud) is its maintained
# successor with the same quantize()/save_quantized() flow
from auto_gptq import AutoGPTQForCausalLM, BaseQuantizeConfig

model_name = "meta-llama/Llama-2-7b-hf"

# Quantization config
quantize_config = BaseQuantizeConfig(
    bits=4,  # 4-bit quantization
    group_size=128,  # Group size for quantization
    damp_percent=0.01,  # Damping factor for Hessian
    desc_act=False,  # Descending activation order
    sym=True,  # Symmetric quantization
    true_sequential=True,  # Sequential quantization
)
# Model naming happens at save_quantized below, not in the config

# Load model
tokenizer = AutoTokenizer.from_pretrained(model_name)
model = AutoGPTQForCausalLM.from_pretrained(
    model_name,
    quantize_config=quantize_config,
    trust_remote_code=True,
)

# Calibration data (needed for Hessian estimation)
from datasets import load_dataset

dataset = load_dataset("c4", "en", split="train")
calibration_data = [
    tokenizer(example["text"], return_tensors="pt")["input_ids"]
    for example in dataset.select(range(128))
]

# Quantize
print("Quantizing model...")
model.quantize(
    calibration_data,
    batch_size=1,
)

# Save quantized model
save_dir = "./llama-2-7b-gptq"
model.save_quantized(save_dir)
tokenizer.save_pretrained(save_dir)

print(f"Model saved to {save_dir}")
```

### Loading GPTQ Model

```python
from auto_gptq import AutoGPTQForCausalLM
from transformers import AutoTokenizer

model_path = "./llama-2-7b-gptq"

# Load quantized model
model = AutoGPTQForCausalLM.from_quantized(
    model_path,
    device_map="auto",
    trust_remote_code=True,
    use_safetensors=True,
)

tokenizer = AutoTokenizer.from_pretrained(model_path)

# Generate
inputs = tokenizer("The future of AI is", return_tensors="pt").to(model.device)
outputs = model.generate(**inputs, max_new_tokens=50)
print(tokenizer.decode(outputs[0]))
```

## GPTQ Parameters Explained

### Group Size

Group size determines how many weights share a scale factor:

```text
group_size=128:
[256, 512] weight
├─ Group 0: [:, 0:128]     ──> scale_0
├─ Group 1: [:, 128:256]   ──> scale_1
├─ Group 2: [:, 256:384]   ──> scale_2
└─ Group 3: [:, 384:512]   ──> scale_3
```

**Trade-offs:**
- Smaller group size (e.g., 64): Better accuracy, slower
- Larger group size (e.g., 128): Faster, slightly worse accuracy
- Group size = -1: Per-tensor (fastest, worst accuracy)

### Damping Percent

Damping prevents numerical instability in Hessian inversion:

```python
# Effective Hessian ≈ H + damp * mean(diag(H)) * I
# Higher damping = more stable but less adaptive

# Default: 0.01 (1% damping)
# Increase if quantization fails
# Decrease for better accuracy (if stable)
```

### Descending Activation

Process weights in order of importance:

```python
desc_act=True:
# Quantize most important weights first
# Better accuracy, slightly slower

desc_act=False:
# Process in natural order
# Faster, minimal accuracy difference
```

| Method | Retraining | Time (7B) | Accuracy @ 4-bit | Speed |

| **GPTQ** | No | 30 min | Good | Fast |

## Performance

### Model Size

```python
import os

def get_model_size(path):
    total_size = 0
    for file in os.listdir(path):
        if file.endswith('.bin') or file.endswith('.safetensors'):
            total_size += os.path.getsize(os.path.join(path, file))
    return total_size / (1024 ** 3)  # GB

fp32_size = get_model_size("./llama-2-7b-fp32")
gptq_size = get_model_size("./llama-2-7b-gptq")

print(f"FP32: {fp32_size:.2f} GB")
print(f"GPTQ 4-bit: {gptq_size:.2f} GB")
print(f"Compression: {fp32_size / gptq_size:.2f}x")

# Typical output:
# FP32: 26.00 GB
# GPTQ 4-bit: 4.20 GB
# Compression: 6.19x
```

## Advanced: Custom Calibration Data

```python
def create_calibration_data(tokenizer, domain_specific_texts):
    """Create domain-specific calibration data"""

    calibration_data = []

    for text in domain_specific_texts:
        # Tokenize
        tokens = tokenizer(
            text,
            return_tensors="pt",
            truncation=True,
            max_length=2048,
        )

        calibration_data.append(tokens["input_ids"])

    return calibration_data

# Usage
code_texts = [
    "def fibonacci(n):\n    return n if n <= 1 else fibonacci(n-1) + fibonacci(n-2)",
    "class NeuralNetwork(nn.Module):\n    def __init__(self):",
    # ... more code examples
]

calib_data = create_calibration_data(tokenizer, code_texts)
model.quantize(calib_data)
```

## Troubleshooting

```python
# Solution: Use CPU offloading during quantization
model = AutoGPTQForCausalLM.from_pretrained(
    model_name,
    quantize_config=quantize_config,
    device_map="auto",
    offload_folder="./offload",
    offload_buffers=True,
)
```

### Issue 2: Slow Quantization

```python
# Solution: Use batch processing
model.quantize(
    calibration_data,
    batch_size=4,  # Increase batch size
)
```

### Issue 3: Poor Accuracy

```python
# Solution: Try different settings
quantize_config = BaseQuantizeConfig(
    bits=4,

```

## Best Practices

1. **Use domain-specific calibration:** Better accuracy for specialized tasks
2. **Group size 128:** Good balance of speed and accuracy
3. **Damping 0.01:** Works for most models
4. **Save in multiple formats:** Offer both GPTQ and AWQ to users
