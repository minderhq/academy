# 3200: Embeddings - Prerequisites

## Before You Start

This module covers word embeddings, positional encodings, and tokenization.

**Required Knowledge:**

### Linear Algebra
- Vector spaces
- Dot product and similarity
- Matrix operations
- Dimensionality reduction

### NLP Basics
- Words as discrete symbols
- One-hot encoding limitations
- Semantic similarity

### ML Basics
- Neural network embeddings
- Training objectives
- Backpropagation

### If you're not familiar:

**Review Resources:**

- "Word2Vec" paper (Mikolov et al.)
- "GloVe: Global Vectors for Word Representation" paper
- 3Blue1Brown: Dot products and duality

**Estimated Review Time:** 3-4 hours
