# 6400: Vector Databases - Prerequisites

**For:** [6401: Qdrant Setup](./6401-Qdrant-Setup.md)

---

## Before You Start

This module covers production vector database deployment: hands-on Qdrant setup, a comparison of managed and self-hosted databases, and a production deployment guide.

**Required Knowledge:**

### Databases
- Database fundamentals
- Indexing strategies
- Query optimization
- CAP theorem

### Vector Search
- Embedding similarity
- Approximate nearest neighbor (ANN)
- HNSW algorithm
- IVF (Inverted File Index)

### Vector DB Features
- Filtering and metadata
- Hybrid search (vector + keyword)
- Multi-tenancy
- Consistency and replication

### If you're not familiar:

**Review Resources:**
- "Approximate Nearest Neighbor Search" survey
- "Efficient Retrieval for RAG" tutorials
- Pinecone, Weaviate, Qdrant documentation
- "Vector Database Performance" benchmarks
