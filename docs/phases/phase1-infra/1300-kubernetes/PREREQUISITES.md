# 1300: Kubernetes - Prerequisites

**For:** [1301: K3s Master-Worker Architecture](./1301-K3s-Master-Worker-Arch.md)

## Before You Start

This module covers Kubernetes for LLM deployment, from K3s cluster setup to container orchestration for inference workloads.

**Required Knowledge:**

### Containers
- Docker fundamentals
- Images and containers
- Docker Compose
- Container networking

### Kubernetes Basics
- Pod concepts
- Services and networking
- Deployments and replication
- Configuration management

### Cloud Native
- Microservices architecture
- Declarative configuration
- Health checks
- Rolling updates

### If you're not familiar:

**Review Resources:**

- Kubernetes documentation - "Concepts" section
- Docker documentation - Get started guides
- "Kubernetes Up and Running" (Burgos, Hightower) - Chapters 1-4
- CNCF Kubernetes training

**Estimated Review Time:** 4-5 hours
