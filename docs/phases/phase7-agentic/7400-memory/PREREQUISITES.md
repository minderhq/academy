# 7400: Memory - Prerequisites

## Before You Start

This module covers memory systems for AI agents.

**Required Knowledge:**

### Agent Systems
- Agent state management
- Context management
- Conversation history
- Session persistence

### Memory Types
- Short-term (ephemeral) memory
- Long-term (persistent) memory
- Semantic memory
- Episodic memory

### Storage Technologies
- Vector databases (semantic search)
- Key-value stores (Redis)
- Graph databases (knowledge graphs)
- SQL databases (structured data)

### If you're not familiar:

**Review Resources:**
- "Memory Systems for AI Agents" research
- LangChain memory documentation
- "Conversational AI" memory patterns
- MemGPT and memory-augmented LLMs
