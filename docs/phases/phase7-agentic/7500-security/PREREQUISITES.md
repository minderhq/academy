# 7500: Security - Prerequisites

## Before You Start

This module covers security considerations for AI agents and systems.

**Required Knowledge:**

### Security Fundamentals
- Authentication and authorization
- Input validation and sanitization
- Rate limiting and abuse prevention
- Secure data handling

### AI-Specific Security
- Prompt injection attacks
- Jailbreaking and adversarial attacks
- Data poisoning
- Model inversion

### Agent Security
- Tool access control
- Execution sandboxing
- Output filtering
- Audit logging

### If you're not familiar:

**Review Resources:**
- "Not what you've signed up for: Compromising Real-World LLM-Integrated Applications with Prompt Injection"
- OWASP Top 10 for LLMs
- "AI Security" papers and guidelines
- NIST AI Risk Management Framework
