# 2100: Tensor Algebra - Prerequisites

## Before You Start

This module covers the mathematical foundations of deep learning: tensor algebra, derivatives, and optimization.

**Required Knowledge:**

### Linear Algebra
- Vector and matrix operations
- Dot products and matrix multiplication
- Eigenvalues and eigenvectors
- Matrix factorization (SVD, QR)

### Calculus
- Derivatives and partial derivatives
- Chain rule
- Gradients and directional derivatives
- Optimization basics

### If you're not familiar:**

**Review Resources:**
- Khan Academy: Linear Algebra course
- Khan Academy: Calculus course
- 3Blue1Brown: Essence of Linear Algebra (YouTube)
- 3Blue1Brown: Essence of Calculus (YouTube)

**Estimated Review Time:** 4-6 hours
