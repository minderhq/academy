# 2200: Frameworks - Prerequisites

## Before You Start

This module covers PyTorch, TensorFlow, and CUDA programming.

**Required Knowledge:**

### Python Programming
- Classes and inheritance
- Decorators and context managers
- Type hints
- Exception handling

### Deep Learning Basics
- Neural network layers (Linear, ReLU, etc.)
- Forward pass
- Backpropagation
- Loss functions

### GPU Concepts
- Why GPUs are faster for ML
- Memory transfer between CPU/GPU
- Parallel processing

### If you're not familiar:**

**Review Resources:**
- PyTorch Tutorial: https://pytorch.org/tutorials/
- TensorFlow Tutorial: https://www.tensorflow.org/tutorials
- CUDA C Programming Guide

**Estimated Review Time:** 3-4 hours
