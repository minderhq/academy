## 📋 What Are Legacy Labs?

These labs were created before the reorganization to a sequential numbering system.
They use a **phase-based numbering scheme** where:
- LAB-2XX = Phase 2 (Foundations)
- LAB-3XX = Phase 3 (Transformers)
- LAB-4XX = Phase 4 (Quantization)
- LAB-5XX = Phase 5 (Fine-tuning)
- LAB-6XX = Phase 6 (RAG)
