# Capstone Projects and Templates

The portfolio track: seven capstone projects (PROJECT-001 through PROJECT-007) plus their prerequisites and a common setup guide, and twelve reusable project templates. Each capstone combines several volumes into one substantial artifact you can show employers; the templates give you production-shaped starting skeletons for your own ideas.
