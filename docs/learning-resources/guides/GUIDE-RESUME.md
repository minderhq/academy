# RESUME TEMPLATES & EXAMPLES

**For:** Minder Academy graduates seeking AI Engineering roles
**Templates Included:** Entry-level, Mid-level, Senior
**Last Updated:** 2026-10-08

---

## CRITICAL ADVICE

### The 10-Second Rule
Recruiters spend ~10 seconds on your resume. Make them count:

1. **Clear hierarchy** - Most important info at top
2. **Quantifiable results** - Numbers, percentages, metrics
3. **Specific technologies** - "PyTorch" not "ML frameworks"
4. **No fluff** - Every word must earn its place
5. **One page** - Two only if 5+ years experience

---

### ATS Optimization
Most resumes go through Applicant Tracking Systems first:

- [ ] Use standard section headings (Experience, Education, Skills)
- [ ] Avoid tables, columns, graphics
- [ ] Include keywords from job description
- [ ] Save as PDF (unless Word requested)
- [ ] Name file: `FirstName_LastName_AI_Engineer_Resume.pdf`

## Resume Checklist

### Before Submitting

**Content:**

- [ ] No typos or grammatical errors
- [ ] All numbers are accurate
- [ ] Links work (GitHub, LinkedIn, portfolio)
- [ ] Tech stack is specific and current
- [ ] No buzzwords without context

**Format:**

- [ ] Consistent formatting (fonts, spacing, bullets)
- [ ] Clean, readable layout
- [ ] One page (two only if senior)
- [ ] Saved as PDF (unless Word requested)
- [ ] Filename: `FirstName_LastName_Role_Resume.pdf`

**Keywords (for ATS):**

- [ ] LLM, Large Language Model, Transformer
- [ ] RAG, Retrieval Augmented Generation
- [ ] Fine-tuning, LoRA, QLoRA
